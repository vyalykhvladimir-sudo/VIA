# ВИА — подбор выгодных грузоперевозок

Веб-приложение, которое сравнивает тарифы двух перевозчиков — **Деловые Линии** и
**Байкал Сервис** — и показывает итоговую стоимость с вашей скидкой, срок доставки
и оптимальный вариант по вашим приоритетам.

Собрано на **Vite + React**. Бэкенда нет: весь расчёт, история и выгрузка отчётов
работают в браузере. Поэтому деплой не может упасть из-за Python-зависимостей —
публикуется обычный статический сайт.

---

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173
```

Сборка и проверка production-версии:

```bash
npm run build        # → dist/
npm run preview      # локальный просмотр собранной версии
```

Требуется Node.js 18+ (проверено на 20).

## Что внутри

| Раздел | Возможности |
|---|---|
| **Подбор** | маршрут из справочника 51 города, вес, места, габариты (объём считается сам), объявленная ценность, лимит срока, дата отправки, формат доставки (терминал / забор / доставка / дверь-дверь), **скидка в процентах отдельным полем**, приоритеты выбора (цена / срок / надёжность) |
| **Результат** | вердикт с ценой и сценой маршрута, 4 ключевых показателя, таблица 10 тарифов с оценкой и метками («оптимум», «дешевле всех», «быстрее всех», «парето»), блок «Что учесть» из 9 пунктов, выгрузка в Excel и CSV |
| **Заявка** | номер `ВИА-ГГГГММДД-000N`, контакт, комментарий, статусы: новая → в работе → завершена |
| **История** | период 30 / 90 дней / год, суммарная и средняя экономия, кто чаще выигрывает, частые маршруты, таблица расчётов и заявок, отметка выбранного варианта |
| **Отчёты Excel** | полный отчёт (Сводка + Заявки + Расчёты), только заявки, только расчёты — настоящие `.xlsx` с оформленными заголовками, автофильтром, закреплённой строкой и денежным форматом |

## Как считается цена

1. Расстояние между городами — по координатам (формула гаверсинуса) с коэффициентом
   извилистости дорог: до 400 км — 1.10, до 1500 км — 1.14, дальше — 1.18.
2. Базовый срок: `ceil(км / 500) + 1`, затем умножается на коэффициент тарифа.
3. Оплачиваемый вес: `max(вес, объём × 250)` — стандартное правило объёмного груза.
4. Цена тарифа: `max(минимум, оплачиваемый вес × ставка за кг) + ставка за км × расстояние`,
   плюс забор/доставка и страхование объявленной ценности.
5. Скидка применяется ко всем тарифам пропорционально; базовая цена остаётся видна.
6. Оценка варианта — взвешенная сумма отклонений по цене и сроку плюс поправка
   на надёжность. Веса задаются ползунками «Приоритеты выбора».

Тарифная сетка (10 тарифов, 2 перевозчика) и все коэффициенты лежат в одном файле —
`src/lib/engine.js`, в объекте `CARRIERS`. Расчёт детерминированный: одинаковый
запрос всегда даёт одинаковую цену.

> Цены рассчитаны по публичным тарифным сеткам перевозчиков. Данные никуда не
> отправляются: и расчёты, и история, и отчёты остаются в браузере.

## Структура проекта

```
index.html                точка входа Vite
vite.config.js            конфиг сборки
vercel.json               настройки деплоя (статика + SPA-роутинг)
src/
  main.jsx                монтирование React
  App.jsx                 роутинг (#/  и  #history) без библиотек
  styles.css              дизайн-система: liquid glass, тёмная и светлая темы
  fonts.css               подключение локальных шрифтов (Unbounded, Manrope, JetBrains Mono)
  app.css                 небольшие правки поверх
  lib/
    engine.js             ядро: гео, тарифы, скоринг, рекомендации
    storage.js            история и заявки в localStorage
    reports.js            сборка отчётов Excel
    xlsx.js               генератор .xlsx без зависимостей (zip + OOXML)
    format.js             форматирование чисел и дат
  components/             форма, результаты, сцена маршрута, окно заявки, иконки
  pages/                  CalculatorPage, HistoryPage
public/
  fonts/*.woff2           шрифты локально — без обращений к CDN
  hero3.jpg               фото для hero-блока
  favicon.svg
```

Шрифты и картинка лежат в проекте, поэтому приложение не зависит от внешней сети
и одинаково выглядит в любом окружении.

## Деплой на Vercel

### Вариант 1 — из GitHub (рекомендуется)

1. Создайте репозиторий и загрузите проект:
   ```bash
   git init
   git add .
   git commit -m "ВИА на Vite"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/via-cargo.git
   git push -u origin main
   ```
2. <https://vercel.com/new> → **Import Git Repository** → выберите репозиторий.
3. Vercel сам определит Vite. Проверьте поля:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Deploy**. Через минуту сайт доступен по адресу вида `via-cargo.vercel.app`.

Все параметры уже прописаны в `vercel.json`, переопределять ничего не нужно.

### Вариант 2 — из папки без Git

```bash
npm install -g vercel
npm run build
vercel --prod
```

### Обновление сайта

Достаточно запушить изменения — Vercel пересоберёт проект сам. Если нужно
передеплоить вручную: **Deployments → ⋯ → Redeploy**.

```bash
npm run build     # должен завершиться без ошибок
```

## Важно знать

- **Данные хранятся в браузере.** История и заявки лежат в `localStorage` —
  они свои у каждого устройства и очищаются вместе с данными сайта. Сервера нет
  по замыслу: так приложение работает мгновенно и ничего не стоит в эксплуатации.
  Если понадобится общая база для нескольких менеджеров — потребуется бэкенд,
  и это отдельная задача.
- **Подключение реальных API.** Вся тарифная логика изолирована в `src/lib/engine.js`:
  функция `compare()` — единственная точка входа. Чтобы перейти на живые цены,
  нужно заменить генерацию предложений на запрос к API перевозчиков и вернуть тот же
  формат объекта. Интерфейс менять не придётся.
- **Кнопка «Загрузить примеры»** на странице истории заполняет её демонстрационными
  расчётами — удобно, чтобы сразу увидеть аналитику и попробовать выгрузку Excel.
